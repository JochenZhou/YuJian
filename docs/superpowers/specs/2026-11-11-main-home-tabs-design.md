# 玉简主页 Tab 化重构设计文档 (Scheme A)

## 1. 背景与目标

当前 [`MainActivity.kt`](file:///c:/Users/zhou/Desktop/项目/玉简/app/src/main/java/com/zqc/tvnotify/MainActivity.kt) 将状态网格、接口地址卡、4 排共 13 个功能按钮、运维说明与双二维码卡片全部堆叠在同一页面中，纵向内容密集，遥控器上下移动链路较长。

本次重构采用 **方案 A（顶部主导航 Tab + 焦点即切 + 一屏免滚动双栏布局）**：
1. 在顶部品牌状态栏下方新增一级横向主导航 Tab 栏，包含三个页签：
   - **Tab 1 · 总览与互联**（古风：`灵台总览` / 现代：`总览与互联`）
   - **Tab 2 · 演练与调控**（古风：`演法调阵` / 现代：`演练与调控`）
   - **Tab 3 · 系统与运维**（古风：`符钥天机` / 现代：`系统与运维`）
2. 遥控器焦点移动到顶部任意主 Tab 按钮上时**立即切换下方页面**（同时保留点击切换兼容鼠标/触控）。
3. 每个 Tab 页面均采用左右双栏对称卡片排版（窄屏自动退化为单列），在 1080p 电视大屏上一屏尽显。

---

## 2. 方案对比与决策

| 方案 | 布局结构 | 优点 | 缺点 | 结论 |
|------|----------|------|------|------|
| **方案 A（选定）** | 顶部一级 3 Tab + 全宽双栏内容区切换 | 彻底消除纵向拥挤，首页直达状态/扫码/音乐，各页双栏呼吸感极佳 | 演练与系统按钮需切到对应 Tab | **采用** |
| **方案 B** | 左栏局部 3 Tab + 右栏二维码常驻 | 二维码永远可见 | 左栏仅占 58% 宽度仍显局促，且存在左主 Tab + 右二维码子 Tab 的双层混淆 | 放弃 |
| **方案 C** | 顶部 4 Tab（控制台/音乐/扫码/设置） | 模块拆分最细 | 扫码与音乐不在首屏，增加日常操作步数 | 放弃 |

## 3. 界面结构与各 Tab 布局

### 3.1 Tab 1：总览与互联（`MainTab.OVERVIEW`）
- **左栏（权重 `1.28f`）**：
  1. **2×2 状态指标网格卡片**（阵法/服务状态、传音/监听端口、显形之术/悬浮窗权限、本机 IPv4；点击未授权时跳转悬浮窗权限设置，已授权时刷新状态）。
  2. **传音符钥与接口地址卡片**（显示当前 Token 徽标与完整 HTTP 调用地址，点击可复制）。
  3. **高频快捷入口卡片**：含 3 个核心操作按钮：
     - `Sendspin 音乐`（纯文字无音乐图标，点击启动 `SendspinActivity`）
     - `试传一简` / `测试通知`（主高亮按钮，短按文字测试，长按 16:9 画卷测试）
     - `传音简录` / `通知历史`（打开历史记录弹窗）
- **右栏（权重 `0.92f`）**：
  - **极速互联二维码卡片**：保留「🌟 HA 自动发现集成」与「📱 手机控制台 & 符钥」双子页签切换、二维码渲染与底部链接点击复制。

### 3.2 Tab 2：演练与调控（`MainTab.PRACTICE`）
- **左栏（权重 `1.0f`）· 演练测试卡片**：
  - 卡片标题与副标题（古风：`四大演法 · 横幅试炼` / 现代：`通知演练 · 效果预览`）。
  - 2×2 演练按钮网格：
    - 第一行：`试传一简 / 测试通知`（短按普通横幅，长按 16:9 多媒体画卷）、`试显画影 / 图片测试`
    - 第二行：`试演灵镜 / 视频测试`、`灵音试诵 / 语音播报`
  - 底部操作提示：说明长按「试传一简」可触发 16:9 多媒体画卷测试。
- **右栏（权重 `1.0f`）· 阵法调控卡片**：
  - 卡片标题与副标题（古风：`阵法调控 · 法相方位` / 现代：`横幅偏好 · 显示与声音`）。
  - 2×2 调控按钮网格：
    - 第一行：`传音简录 / 通知历史`、`方位：... / 位置：...`
    - 第二行：`闭关免扰 / 提示声音`、`主题：...`（短按打开 8 大主题选择弹窗，长按循环切换下一个主题）

## 4. 遥控器焦点与状态保持规范

1. **焦点即切（Focus-follows-tab）**：
   - 顶部 3 个主导航按钮获得遥控器焦点（`hasFocus == true`）时立即调用 `selectMainTab(tab)` 切换对应页面。
   - 顶部主导航栏左右边界锁定：`overviewTabButton` 的左焦点锁定自身，`systemTabButton` 的右焦点锁定自身，避免在顶部按左右键意外跳入下方右栏。
2. **选中态与聚焦态区分**：
   - **聚焦态（Focused）**：`theme.accentColor` 实心背景 + `2dp` 纯白描边 + 纯白文字 + `1.04x` 微缩放。
   - **选中未聚焦态（Selected & Unfocused）**：当焦点下移到内容区时，当前所属主 Tab 按钮保持高亮半透明底色（`0x44` Alpha 的 `theme.accentColor`）+ `2dp` `theme.accentColor` 描边 + 纯白文字，清晰指示当前所在页签。
   - **未选中态（Inactive）**：`theme.cardBg` 底色 + `1dp` `theme.cardStroke` 描边 + `theme.hintColor` 文字。
3. **主题切换保持当前 Tab**：
   - 在 Tab 2 点击或长按 `themeButton` 切换主题重建视图时，`activeMainTab` 保持为 `MainTab.PRACTICE`，视图重建后直接显示 Tab 2 并将焦点恢复到 `themeButton`。
4. **返回键优化**：
   - 当焦点位于页面内容区且当前不在顶部主 Tab 按钮上时，按遥控器返回键优先将焦点移回当前选中的顶部主 Tab 按钮；若焦点已在顶部主 Tab 按钮上，在非首页切回首页，在首页则正常退出应用。

## 5. 约束条件

- 严格兼容 `minSdk = 23`（Android 6.0），纯 Kotlin + Android 原生 View 构建，不引入额外 UI 依赖。
- 保持「Sendspin 音乐」按钮文案为纯文本 `"Sendspin 音乐"`（不带音乐符号图标）。
